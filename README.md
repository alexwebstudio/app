# VOKU — ресторан китайской кухни (прототип)

Мобильный прототип приложения ресторана китайской кухни на **Next.js (App Router) + React**, без TypeScript.
Сценарий — заказ за столом по QR-коду: гость открывает меню, выбирает блюда, видит корзину и профиль с бонусами.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000 (приложение рассчитано на мобильную ширину, адаптируется под планшет/десктоп).

Автовыбор стола по QR-коду — параметр в URL: `http://localhost:3000/?table=5` (или `?t=5`).

Прод-сборка:

```bash
npm run build
npm start
```

> Примечание: проект лежит в WSL (Ubuntu). Для запуска нужен Node.js **внутри** WSL
> (например, через `nvm`), либо запускайте из Windows. `node_modules` в репозиторий не входит.

## Структура

```
app/
  layout.js         # корневой layout, метаданные, провайдеры (Table + Cart)
  page.js           # роутинг разделов (Главная/Корзина/Профиль), модалки, QR
  globals.css       # дизайн-система: шрифты, палитра, скругление 50px, адаптив, a11y
components/
  Preloader.js      # экран загрузки с логотипом VOKU
  Header.js         # шапка: логотип + подпись, кнопка стола, корзина
  PromoSlider.js    # промо-слайдер (автолистание, свайп, стрелки, точки)
  CategoryTabs.js   # горизонтальные категории (SVG-иконки) с фильтрацией
  ProductCard.js    # карточка блюда + степпер количества
  ProductGrid.js    # каталог с фильтром по категории
  ProductModal.js   # детальная карточка блюда (модалка)
  CartView.js       # раздел «Корзина»: список, итог, бонус 3%
  ProfileView.js    # раздел «Профиль»: вход/бонусы/инфо/история
  TableModal.js     # выбор стола (8 столов) + пояснение про QR
  AuthModal.js      # демо-регистрация / вход в личный кабинет
  BottomNavigation.js # нижняя навигация (4 пункта) с анимированным индикатором
  Toast.js          # уведомления
  DishImage.js      # фото блюда с фирменным плейсхолдером (SVG-иконка)
  Icons.js          # инлайн-SVG иконки и логотип (без эмодзи)
context/
  CartContext.js    # состояние корзины + сохранение в localStorage
  TableContext.js   # выбранный стол, чтение QR-параметра, localStorage
  AuthContext.js    # демо-авторизация (localStorage, без сервера)
data/
  categories.js     # категории меню
  products.js       # каталог блюд (цены в тенге)
  promos.js         # промо-слайды
  tables.js         # 8 столов + валидация номера
  profile.js        # демо-профиль и бонусная программа (3%)
lib/
  format.js         # форматирование валюты (только тенге, ₸)
public/fonts/       # Seenonim (заголовки), Horovod (текст) + лицензия
```

## Шрифты

- **Seenonim** — заголовки (`--font-brand`).
- **Fredoka One** — описания и весь основной текст (`--font-body`). Лицензия SIL OFL, свободен для встраивания (см. `public/fonts/FredokaOne-LICENSE.txt`).

Подключены как `@font-face` в `globals.css`. Файлы шрифтов лежат в `public/fonts`. Меняются в одном месте — переменных `--font-brand` / `--font-body` в `:root`.

## Кастомизация

- **Скругление:** переменная `--radius` в `globals.css` (сейчас `50px`) — единая для всех элементов.
- **Валюта:** `lib/format.js` — везде используется `formatPrice()` (тенге).
- **Данные:** блюда, категории, промо, столы, профиль вынесены в `data/*`.

## Что реально работает

- Автовыбор стола по QR-параметру, ручной выбор из 8 столов, сохранение выбора между разделами и перезагрузками.
- Каталог с фильтром по категориям, детальные карточки блюд (модалки).
- Корзина с изменением количества, итогом в тенге и расчётом бонусов 3%; сохранение в localStorage.
- Нижняя навигация из 4 пунктов (Главная/Меню/Корзина/Профиль) с анимированным индикатором; «Меню» прокручивает к каталогу.
- Демо-регистрация и вход в личный кабинет (localStorage): имя/телефон/пароль, выход, сохранение сессии между перезагрузками.
- Профиль с демонстрационным бонусным балансом и историей.

## Что демонстрационное

- Данные (блюда, промо, столы, профиль, история бонусов) — статичные, в `data/*`.
- Фото блюд — временные, со стока Unsplash; при недоступности показывается фирменный плейсхолдер.
- Кнопка «Оформить заказ» — только демо-уведомление, реальный заказ не создаётся.
- Регистрация/вход — демо: аккаунты хранятся в localStorage браузера в открытом виде, без сервера и шифрования. Не для реальных паролей.

## Что нужно на серверной стороне для «боевой» версии

- **Заказы:** приём заказа, статусы, привязка к столу, интеграция с кухней/кассой.
- **QR-привязка столов:** генерация QR со ссылкой `?table=<id>`, реальный список и статусы столов.
- **Бонусная система:** аутентификация гостя, реальный баланс, начисление/списание, история.
- **Каталог и промо:** управление из админки/CMS, реальные фотографии блюд.
- Оплата, доставка/самовывоз (при необходимости) — через проверенных провайдеров, секреты только на сервере.
